  # HemoChain

## Sobre o Projeto
Um Sistema inteligente para gestão da cadeia de hemocomponentes, integrando estoque, compatibilidade, validade e distribuição hospitalar com segurança e eficiência.



## Tecnologias usadas: 
Java e SpringBoot
